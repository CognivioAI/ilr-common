# Reference Architecture Library

> Architecture Agent — Pre-built Architectural Blueprints

---

## Purpose

Instead of designing from scratch every time, the Architecture Agent starts
by finding the closest reference architecture and customising it.

---

## Available Reference Architectures

| Architecture | Best For |
|-------------|----------|
| `monolith.md` | MVP, single team, rapid validation |
| `microservices.md` | Multi-team, independently deployable |
| `event-driven.md` | Async processing, multiple consumers |
| `serverless.md` | Low-ops, variable traffic, event-triggered |
| `ai-platform.md` | Multi-agent AI with orchestration |
| `rag.md` | Semantic search, knowledge bases |
| `document-processing.md` | File upload → processing → output |
| `workflow.md` | Long-running processes, human approvals |
| `hybrid.md` | Combination of patterns |

---

## How to Use

1. Pattern Recognition module identifies the primary pattern
2. Look up the closest reference architecture here
3. Customise for specific requirements
4. Document deviations in an ADR
